# ++PHP Language RFCs

This directory records accepted and proposed language contracts independently
from their implementation schedule. Acceptance settles a design; it does not
make syntax available before the stage named by the RFC.

The [canonical plan](../ppphp-mvp-end-to-end-plan.md#stage-15--immutable-records-native-type-ergonomics-and-declarative-framework-metadata)
records the same schedule. The project owner may regroup or reorder unimplemented
work; update the plan, this index and affected references together. Stage 15C
covers Scalar Objects, Stage 15D covers List And Map Objects including path
access, and Stage 15E reserves the proposed Attribute Factory Expressions work.
Scheduling a draft does not accept its unresolved design.
