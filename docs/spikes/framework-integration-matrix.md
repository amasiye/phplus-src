Inspected **2026-09-05**. This is a research/feasibility matrix, not supported-version advertising. Package versions below were retrieved from publisher metadata on `repo.packagist.org/p2/<package>.json`; source revisions identify the inspected release. WordPress and Joomla use their official version/release services instead. Installation evidence exists only for the two launch probes; source inspection is not runtime proof.

## Tempest Handoff Details

At the pinned source, `packages/discovery/src/AutoloadDiscoveryLocations.php` reads Composer installed metadata: Tempest packages, packages requiring Tempest, and explicit `extra.tempest.can-discover` opt-ins. `DiscoveryLocation.php` maps `.php` paths to classes and hashes the location path. `packages/core/src/Tempest.php` accepts explicit locations and internal storage. `packages/discovery/src/DiscoveryCache.php` stores per-location discovery under internal storage. Therefore external cache configuration is plausible, but relocated cache validity is **not proved**.

`packages/generation/src/Php/StubFileGenerator.php` calls `src_namespace($targetPath)` and imports the stub into `ClassManipulator`; that class uses `Nette\PhpGenerator\ClassType::fromCode/from`. Retargeting Composer runtime roots without source-aware generation risks writes to generated output. Renaming files does not make this PHP importer parse ++PHP.

Next real fixture: typed route/controller, DI service, event handler, console command, co-located view, ordinary configuration, migration; check/build then discovery/view caches; edit/add/rename/delete; fail discovery after a successful compile; clean/missing-output recovery; external writable cache; source-free relocation; final HTTP/CLI execution. Include only selected generated PHP and intended dependencies. Exclude tests/staging/stale classes. Preserve concrete attributes; never evaluate `.ppphp` directly.

Template errors use Tempest's [view source mapping](https://tempestphp.com/blog/view-source-mapping), while application frames use ++PHP source maps. No breakpoint/debugger support claim is made. No Tempest package was installed into the compiler or added as a third launch requirement.
