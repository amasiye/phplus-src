## Contribute

Thare are many ways to [contribute](/CONTRIBUTING.md) to PHPlus.
- [Submit bugs](https://github.com/amasiye/phplus-src/issues) and help us verify fixes as they are checked in.
- Review the [source code changes](https://github.com/amasiye/phplus-src/pulls)
- Engage with PHPlus developers on [StackOverflow](https://stackoverflow.com/questions/tagged/phplus)
- Help each other on the [PHPlus Community Discord](https://discord.gg/phplus)
- Join the [#phplus](https://x.com/search?q=%23PHPlus) discussion on X.com
- [Contribute bug fixes](/CONTRIBUTING.md)
